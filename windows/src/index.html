Connect external AI agents to Clawvinci via HTTP SSE at http://127.0.0.1:19789/mcp.

1. Claude Desktop (Windows)
Add this entry to %APPDATA%\Claude\claude_desktop_config.json:
{
  "mcpServers": {
    "clawvinci": {
      "type": "http",
      "url": "http://127.0.0.1:19789/mcp"
    }
  }
}
2. Cursor IDE
Add this to %USERPROFILE%\.cursor\mcp.json:
{
  "mcpServers": {
    "clawvinci": {
      "type": "http",
      "url": "http://127.0.0.1:19789/mcp"
    }
  }
}
3. Claude Code CLI
Run this command in PowerShell:
claude mcp add --transport http clawvinci http://127.0.0.1:19789/mcp
4. Codex CLI
Run this command in PowerShell:
codex mcp add clawvinci --url http://127.0.0.1:19789/mcp
